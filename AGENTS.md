# Для ИИ-агентов: установка AgeCMS

Этот файл читает агент, которого попросили поставить AgeCMS. Правка уже работающего сайта описана в `core/agent.md` (на сайте он отдаётся как `/AGENT.md`).

## Свой сервер на Debian или Ubuntu

Если у вас root на сервере с Debian или Ubuntu, всё ниже делает одна команда: PHP с расширениями, nginx (или уже стоящий Apache), права, виртуальный хост, сертификат Let's Encrypt, установка и ночной бэкап.

```bash
curl -fsSL https://raw.githubusercontent.com/likvp/AgeCMS/main/install.sh | sudo bash -s -- example.com --name="Название"
```

В конце она печатает адрес админки и пароль администратора: передайте его владельцу, в журналы и чаты не копируйте. Параметры: `--email=`, `--admin=`, `--password=`, `--dir=`, `--web=nginx|apache`, `--php=8.4`, `--no-ssl`, `--no-demo`. Журнал: `/var/log/agecms-install.log`. Если сертификат не получен (домен ещё не смотрит на сервер), сайт работает по http, позже выполните в каталоге сайта `certbot --nginx -d example.com`, затем `sudo -u www-data php bin/config.php set site_url https://example.com` и `sudo -u www-data php bin/rebuild-cache.php --all`. После этого переходите к шагу 5 ниже. На хостинге с панелью, на другой системе или со своим веб-сервером ставьте по шагам.

## Порядок установки

1. **Проверьте среду, до установки.**
   ```bash
   php bin/requirements.php
   ```
   Строки `НЕТ` обязательны, строки `СОВЕТ` нужны для возможностей сайта (особенно `sodium` или `openssl`: без обоих не работает кнопка «Обновить», без `sodium` не проверяются модули с подписью разработчика Ed25519, `gd` с WebP: сжатие картинок, `zip`: резервные копии, `curl`, `openssl`). В каждой строке написано, как поставить: пакет для Debian/Ubuntu, Remi, Alpine, Docker или шаг в панели хостинга.
2. **Поставьте всё, что названо, сами**, не пропускайте `СОВЕТ`. На своём сервере: пакеты через `apt`/`dnf`/`apk`, затем перезапуск PHP-FPM и веб-сервера. На хостинге с панелью (ISPmanager, cPanel, Plesk): раздел «Расширения PHP» или «Выбор версии PHP», включите нужное для версии PHP этого сайта. Если расширения нет в панели, переключите сайт на версию PHP, где оно есть, а если нет нигде, составьте для владельца текст заявки в поддержку хостинга и скажите об этом явно. Ничего не пропускайте молча. Из админки («Система», «Требования сервера») то же умеют кнопки «Установить» и «Установить недостающее»: если PHP сайта работает от root или с sudo без пароля, они ставят пакеты сами, иначе показывают команды и текст для поддержки хостинга.
3. **Повторите `php bin/requirements.php`**, пока не будет «Всё необходимое есть» (код 0). Для автоматической проверки: `php bin/requirements.php --json` (код 1: нет обязательного, код 2: нет только рекомендуемого, `--strict`: считать код 2 ошибкой).
4. **Установите**: `php bin/install.php --url=https://адрес-сайта --name="Название"` (с `--strict`, если установка не должна идти без рекомендуемых расширений). Пароль администратора печатается один раз: передайте его владельцу или сохраните в его хранилище, в журналы и чаты не копируйте.
5. **Проверьте PHP веб-сервера**, он может отличаться от консольного (другой php.ini, другая версия): откройте в админке «Система», блок «Требования сервера», или вызовите `get_site_structure` и посмотрите поле `environment` (`missing_required`, `missing_recommended`). Если там чего-то нет, а в консоли есть, расширение подключено не тому PHP: исправьте `php.ini` или версию PHP именно у сайта и перезапустите PHP-FPM.
6. **Права**: пользователь, от которого работает PHP, должен писать в `data/`, `assets/cache/`, `assets/uploads/`, а для кнопки «Обновить» ещё в `core/`, `admin/`, `bin/`, `assets/` (кроме `cache` и `uploads`), `themes/default`, `index.php`, `.htaccess`. Не открывайте `0777`: сделайте владельцем пользователя PHP (после `git pull` от root выполните `chown -R пользователь:группа каталог`).
7. Настройте веб-сервер (`.htaccess` для Apache, `nginx.vhost.example` для nginx), откройте `/admin/`, войдите и смените пароль.

## Что сказать владельцу в конце

Версия PHP и пакет, какие расширения поставлены и чем (команда или шаг панели), что осталось не поставленным и почему, где лежит пароль администратора.
