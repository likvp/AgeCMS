# Темы AgeCMS

Тема лежит в `themes/<имя>/`: манифест `theme.json`, общий шаблон `layout.php` и шаблоны блоков `blocks/<тип>.php`. Активная тема задаётся настройкой `active_theme`. Картинки, стили и скрипты темы отдаются веб-сервером как обычные файлы (`/themes/<имя>/...`), PHP внутри папки темы снаружи не выполняется.

## theme.json

```json
{
    "name": "karat",
    "title": "Karat",
    "version": "1.0.0",
    "cache_pages": ["kontakty"],
    "settings": {
        "header": {
            "hint": "Что стоит в шапке",
            "fields": {
                "tagline": {"type": "string", "max": 80, "label": "Подпись рядом с логотипом"},
                "show_phone": {"type": "bool", "label": "Показывать телефон", "default": true}
            }
        },
        "footer": {
            "fields": {
                "note": {"type": "text", "max": 300, "label": "Текст в подвале"}
            }
        }
    },
    "blocks": {
        "hero": {
            "title": "Первый экран: заголовок и кнопка",
            "fields": {
                "h1": {"type": "string", "max": 200, "required": true},
                "cta_url": {"type": "url"}
            }
        }
    }
}
```

- `blocks`: типы блоков и их поля. Типы полей: `string`, `text`, `url` (с `"media": true` это картинка из медиа), `int` (`min`, `max`), `bool`, `enum` (`values`, подписи в `labels`), `list` (`of`, `max`). У поля можно задать `label` и `hint` для формы. Название блока до двоеточия идёт в окно «Добавить блок», после двоеточия подсказкой.
- `cache_pages`: страницы, содержимое которых layout показывает на каждой странице. Правка такой страницы сбрасывает весь кэш.
- `settings`: поля шапки и подвала, ниже.

## Настройки шапки и подвала (settings)

Тема объявляет поля в разделах `header` и `footer` теми же словами, что поля блоков, но без `list` (типы `string`, `text`, `url`, `enum`, `bool`, `int`). У раздела можно задать `hint`: текст над формой. У поля `default`: значение, пока владелец ничего не сохранил.

- Админка рисует форму сама: «Настройки», вкладки «Шапка» и «Подвал». Если тема раздела не объявила, вкладка так и говорит.
- Значения лежат в таблице `settings` с ключами `theme.<раздел>.<поле>` (`theme.footer.note`), проходят ту же проверку, что поля блоков (`SchemaValidator`), и попадают в историю как ревизия `@settings`.
- ИИ-агент видит поля в `theme_settings` ответа `get_site_structure` и меняет их через `set_settings`: `{"values": {"theme.footer.note": "Работаем без выходных"}}`.
- В `layout.php` они приходят массивом `$themeSettings` уже с типами: `$themeSettings['header']['show_phone']` это `true` или `false`, у `int` число или `null`, у строк строка (пустая, если не задано).

Общие настройки сайта (название, логотип, телефоны, почта, ИНН, адрес) задаются во вкладке «Главное» и лежат в `$settings`: `site_name`, `org_logo`, `org_phone`, `org_phone2`, `org_email`, `org_inn`, `org_legal_name`, `org_address`. В шаблонах блоков, где `$settings` нет, их читает `ag_setting('org_phone')`.

## layout.php

Получает переменные: `$doc` (страница), `$slug`, `$settings` (все настройки сайта), `$themeSettings`, `$head` (готовые теги для `<head>`), `$content` (блоки страницы), `$menus` (`header` и `footer`, списки `{title, url}`), `$editing` (идёт правка на месте), `$csrf`.

В режиме правки тема подключает `/assets/editor.js` и кладёт `<meta name="ag-csrf" content="...">`, как в `themes/default/layout.php`. Остальное делает ядро:

- **Полоса «Режим редактирования».** Ядро вставляет её сразу после `<body>`, тема свою не рисует (старая тема со своим элементом `.ag-bar` вторую полосу не получит). Высота полосы лежит в CSS-переменной `--ag-bar-h` на `<html>`, вне режима правки её нет. Липкая шапка темы встаёт под полосу так: `.site-header { position: sticky; top: var(--ag-bar-h, 0); }`.
- **Зоны.** Шапка, меню и подвал размечаются атрибутом: `data-ag-region="header"`, `"menu"`, `"footer"`. В режиме правки при наведении на зону появляется карандаш, он ведёт в нужную вкладку настроек (`/admin/?s=settings&tab=header`, `menu`, `footer`). Меню внутри шапки побеждает шапку.
- **Плашка о cookie.** Ядро добавляет её в конец `<body>` на всех страницах для посетителей, пока владелец её не выключил во вкладке «Сайт». Если тема рисует свою, достаточно поставить на неё атрибут `data-ag-cookie`, тогда ядро свою не добавит.
- **Кнопка с карандашом** в углу страницы для вошедшего администратора и режим правки (`/_/edit`) тоже от ядра.

Шаблоны не печатают ничего, кроме текста через `ag_e()`: пользовательский HTML в полях не хранится. Поле, которое можно править прямо на странице, помечается `<?= ag_edit('h1') ?>` в теге (для многострочного `ag_edit('text', true)`).

Политика безопасности страниц разрешает скрипты и стили только из файлов сайта: никаких `<script>` с кодом внутри страницы и атрибутов `style`.
