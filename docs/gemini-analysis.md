## Что хочет Валентин

Чаты 1-6 дают функциональный объём, ТЗ v2.0 дало архитектурные и защитные требования. Где они спорят, побеждает v2.0.

## Где v2.0 исправляет Gemini (решения)

| Тема | Gemini | AgeCMS |
| --- | --- | --- |
| Установка | автоинициализация БД на первом запросе | только CLI `bin/install.php` или веб-установщик с ключом из `data/install.key`, потом `data/install.lock` |
| Вход админа | пароль `2027`, кука `admin_session=true` | пользователи с `password_hash`, PHP-сессия, CSRF, лимит попыток |
| MCP | без авторизации | Bearer-токен (хэш в БД), роли, лимит запросов |
| Запись агентов | прямой UPDATE | очередь `data/queue/` + один писатель под `flock`, `BEGIN IMMEDIATE` |
| Ревизии | полный снимок на каждую правку, таблицу можно менять | JSON Patch (RFC 6902) + чекпойнты, триггеры запрещают UPDATE/DELETE, цепочка хэшей |
| Массовые правки | нет защиты | Circuit Breaker: больше 15% страниц за сессию, откат транзакции и заморозка |
| Скилы | читаются без проверки | подпись манифеста модуля (HMAC или Ed25519) и хэши всех файлов |
| Расположение БД | `data.sqlite` в корне сайта | `data/data.sqlite`, каталог закрыт в `.htaccess` и nginx |
| Канонический URL, sitemap | из `$_SERVER['HTTP_HOST']` (подмена Host) | `site_url` из конфига |
| Вебхуки | подстановка в строку JSON | подстановка только в строковые листья, защита от SSRF |
| Honeypot-таймер | время формы приходит от клиента | токен с HMAC-подписью времени |
| Кэш-файл | `md5(slug).html`, веб-сервер не найдёт | `assets/cache/<slug>.html`, читается nginx/Apache напрямую |
| SSE-стример | бесконечный цикл `sleep(10)` в PHP-воркере | не делаем: на дешёвом хостинге съест все воркеры |
| Теги инвалидации | `CacheManager::clear()` сносит всё | теги `page:<slug>`, `menu:<name>`, `settings`, `theme:<name>` |

## Не делаем в первой версии

- ContextRouter (гео и устройство): в чатах упомянут в дереве файлов, поведение нигде не описано. В `ROADMAP.md`.
- SSE: см. таблицу.
- Готовая скомпилированная сборка Tailwind: тема на собственном CSS без сборки. Tailwind можно подключить позже без смены ядра.
- Pruning ревизий удалением: противоречит append-only. Вместо этого чекпойнты; архивация в `ROADMAP.md`.
