# Захват сайта для режима «Точная копия»

Локальная программа для компьютера владельца. Открывает сайт в Chrome так, как его видит посетитель, сохраняет каждую страницу со всеми файлами (стили, скрипты, картинки, шрифты, фоны) и собирает пакет. Модуль импорта AgeCMS (`modules/importer`) превращает пакет в страницы, которые выглядят и работают как у источника, оставаясь страницами AgeCMS: свой адрес, SEO-поля, 301 со старых адресов, история изменений, откат, поиск, карта сайта, llms.txt.

Программа не нужна на сервере сайта и не входит в обновления ядра («Обновить» её не доставляет). Сервер с PHP браузера не требует.

## Что нужно

- Node.js 20 или новее.
- Chrome или Chromium на этой машине (путь можно указать `--chrome=`).
- Один раз: `npm install` в этой папке (ставится только `playwright-core`, своих браузеров он не качает).

## Запуск

```bash
cd tools/capture
npm install
node capture.mjs https://old-site.ru --out=./capture-old-site --zip
```

Источник: адрес сайта, папка со статическим сайтом или zip (экспорт Tilda и подобные; папка отдаётся локально на время захвата). Результат: папка пакета и, с `--zip`, файл `capture-….zip`.

Параметры:

| Параметр | Что делает |
| --- | --- |
| `--out=ПАПКА` | куда положить пакет |
| `--zip[=ФАЙЛ]` | упаковать пакет в zip для загрузки в админку |
| `--limit=N` | сколько страниц взять (50 по умолчанию, не больше 2000) |
| `--delay=МС` | пауза между страницами (800 по умолчанию, у чужих сайтов не меньше 500) |
| `--mode=auto\|source\|dom` | что сохранять; `auto` выбирает сам (см. ниже) |
| `--pages=/a,/b` | только эти страницы (главная берётся всегда) |
| `--exclude=РЕГВЫР` | не брать адреса под выражение |
| `--no-robots` | не смотреть robots.txt (только для своего сайта) |
| `--no-mobile` | не открывать версию для телефона |
| `--no-verify` | не сверять копию с оригиналом |
| `--no-phone-variant` | не делать отдельный файл для телефона |
| `--max-file-mb=N`, `--max-total-mb=N` | предел файла (30) и пакета (500) |
| `--chrome=ПУТЬ` | свой Chrome |
| `--cache=ПАПКА`, `--no-cache` | дисковый кэш ответов сайта |
| `--keep-work` | оставить снимки и рабочие файлы `.work` |

Если на машине импорта стоят node и Chrome, консольный импорт сам вызывает захват: `php modules/importer/bin/import.php https://old-site.ru --apply` (режим по умолчанию «точная копия»).

## Что делает захват

1. Обходит сайт: главная, `sitemap.xml`, ссылки со страниц; соблюдает robots.txt, паузу, лимит, повтор при ошибке. Чужие сайты читаются вежливо, со своим User-Agent.
2. Открывает каждую страницу в Chrome дважды: компьютер 1280 px и телефон 390 px (масштаб 2). Прокручивает страницу, чтобы подгрузились ленивые картинки и анимации.
3. Сохраняет страницу одним из двух способов:
   - `source`: исходный HTML сайта вместе с его скриптами; все адреса файлов заменены на локальные. Работают слайдеры, меню-бургер, аккордеоны, анимации. Лучший вариант, пока скрипты не зависят от чужого сервера.
   - `dom`: итоговое дерево страницы после работы скриптов, скрипты убраны. Подходит для сайтов, которые собирают содержимое скриптом (Wix, часть Tilda). Меню-бургер и всплывающие окна без скриптов не работают.
   - `auto` берёт `source`, обслуживает пакет у себя, сравнивает снимки копии и оригинала и при сходстве ниже 90% пробует второй способ и оставляет лучший. Результат сверки записан в манифест.
4. Если телефонная версия страницы строится скриптом под ширину экрана и сходство ниже 90%, делает отдельный файл для телефона (`pages/NNNN.m.html`). На AgeCMS он отдаётся по `?ag_view=m`, экраны уже 768 px перенаправляются на него.
5. Все файлы (CSS, JS, картинки, `srcset`, фоны из CSS, шрифты, значки, видео-файлы, JSON) сохраняются в `files/<хост>/<путь>`, ссылки внутри CSS и JS переписываются.
6. Не переносит счётчики, трекеры и чаты (Яндекс Метрика, Google Analytics, пиксели Facebook и VK, Top.Mail.ru, виджеты чатов, статистика Tilda, кнопки соцсетей): их запросы обрываются, адреса в скриптах сайта указывают на пустой файл `files/_blocked/empty.js`, чтобы скрипты не ломались. Всё убранное перечислено в журнале и в отчёте импорта.
7. Формы запоминает (адрес, поля). Импорт подключает форму к заявкам AgeCMS, если это просто и надёжно; иначе пишет в отчёте «форма не подключена». Скрипты форм плагинов (Contact Form 7, WPForms и подобные) не переносятся, они обращались к старому серверу.
8. Внешним остаётся только то, что нельзя сделать локально: карты и ролики YouTube и Vimeo во фреймах.

## Формат пакета

```
manifest.json          формат agecms-capture/1: страницы (адрес, файл, режим, сверка, формы, замечания), итоги
pages/0001.html        страница, 0001.m.html: версия для телефона, если нужна
files/<хост>/<путь>    файлы сайта
capture.log            журнал захвата
```

Адреса файлов внутри страниц записаны как `/__agecms_copy__/<хост>/<путь>`; импорт заменяет их на `/assets/uploads/copy/<ключ>/`.

## Безопасность

- Захват идёт с компьютера владельца. Сервер AgeCMS чужие адреса при этом не открывает.
- Загрузка пакета и перенос страниц доступны только администратору (`system.manage`); в админке показано предупреждение: чужой код попадает на сайт.
- Импорт проверяет каждую запись пакета: только буквы, цифры и `._~-/`, без `..`, без серверных расширений (`.php`, `.phtml`, `.phar`, `.htaccess`, `.cgi`, `.pl`, `.py`, `.sh`), только известные типы файлов, предел размера записи и пакета; SVG очищается от скриптов и обработчиков.
- Страницы копии отдаёт PHP со своей политикой CSP; остальной сайт остаётся со строгой. Подробности в `modules/importer/README.md`.
- Скрипты с чужих хостов в страницах не остаются: их файлы сохраняются локально, а счётчики и виджеты убираются.

## Ограничения

- Нужны Chrome и Node на машине владельца. Пакет бывает большим (десятки мегабайт на сайт с фотографиями).
- Страницы режима `dom` без скриптов: слайдеры показывают первый слайд, бургер и всплывающие окна не открываются.
- Код, который зависит от серверной части старого сайта (поиск, корзина, ajax-формы, личный кабинет), в копии не работает.
- Сверка сравнивает снимки: она показывает, что страница похожа, но не доказывает, что работает каждая кнопка.
